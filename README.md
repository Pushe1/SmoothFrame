# SmoothFrame 2.0

SmoothFrame is a small client-side performance diagnostics and optimization project for Minecraft 26.2 + NeoForge 26.2.

## Current implementation

- Frame timing sampled from `RenderFrameEvent.Pre/Post`.
- 1% and 0.1% low FPS derived from recent frame-time percentiles.
- Long-frame counter.
- JVM GC observation without calling `System.gc()`.
- Optional debug HUD using the 26.2 GUI extraction API.
- No custom worker threads touching Minecraft state.
- No fake Vec3 pooling.
- No placeholder `return true` culling implementation.

## Important

This is an intermediate development build, not a claim of universal stutter elimination. The next stages should integrate only verified 26.2 render/input hooks and benchmark each optimization independently.

## Build

Use Java 25 and the Gradle wrapper generated by the official NeoForge 26.2 ModDevGradle MDK. The official 26.2 template currently uses ModDevGradle 2.0.148 and Java 25.

## Implemented in 2.0.0-dev

- Low-overhead frame-time profiler using NeoForge 26.2 frame events.
- 1% and 0.1% low calculations from a rolling sample history.
- Periodic GC telemetry without forcing garbage collection.
- Optional spike logging.
- Distance-based entity name-tag culling using `RenderNameTagEvent.CanRender`; it does not modify entity simulation.
- Distance-based living-entity render culling using the cancellable `RenderLivingEvent.Pre`; it suppresses only the visual submission and leaves ticking/AI untouched.

The remaining render/chunk/input optimizations are intentionally not enabled as fake implementations. They will only be added after their 26.2 integration points are verified.
